# Concurrent Program Schemes and Their Interpretations

**Reference:** Antoni Mazurkiewicz (1977). *Concurrent Program Schemes and Their Interpretations*. DAIMI Report Series 6(78), Aarhus University. [Open access](https://tidsskrift.dk/daimipb/article/view/7691). [DOI](https://doi.org/10.7146/dpb.v6i78.7691).

## Summary

Mazurkiewicz models a concurrent program scheme by traces of action occurrences. The paper defines the least equivalence relation on words that permits adjacent independent symbols to swap: `w′abw″ ≡ w′baw″` when `a` and `b` are independent. A [[Mazurkiewicz Trace|trace]] is one equivalence class. It can also be represented as a partially ordered set of symbol occurrences, so a linear execution is one serialization of the same causal order.

The report gives equations for the trace language generated by a scheme and shows that their solutions are regular trace languages. It then interprets scheme symbols as actions equipped with resources and state transformations, lifting results about abstract schemes to concurrent programs and their correctness. This is the sequence-first route to true concurrency: begin with executions as words, then quotient away order that carries no causal information.

## Key Ideas

- An independence relation identifies pairs of actions that may commute.
- The congruence generated by swapping adjacent independent actions groups equivalent schedules into one trace.
- Each equivalence class corresponds to a labeled partial order of action occurrences.
- Concurrent-program schemes denote trace languages rather than ordinary word languages.
- Interpretations assign resources and transformations to abstract action symbols.
- Regular trace languages extend finite-state language methods to partial-order behavior.

## Conceptual Contribution

- **Claim:** Sequential observations that differ only in the order of independent actions should denote the same concurrent behavior.
- **Mechanism:** A partial-commutation congruence on words and the equivalent partial-order representation of each trace.
- **Concepts introduced/used:** [[Mazurkiewicz Trace]], [[Independence Relation]], [[Trace Language]], [[Partial Order]]
- **Stance:** algebraic / language-theoretic true concurrency.
- **Relates to:** Recovers partial-order executions from sequences by erasing causally irrelevant scheduling choices.
