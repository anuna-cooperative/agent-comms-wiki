# Higher-Order Knowledge

**Notation:** `K_i K_j φ; E_G^k φ`.

Knowledge about knowledge: for example, agent i knows that agent j knows φ. Repeating “everyone knows” k times gives E_G^k φ. Common knowledge requires every finite depth; a particular finite chain of acknowledgements generally establishes only limited depth.
