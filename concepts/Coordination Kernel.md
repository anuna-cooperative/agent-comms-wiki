# Coordination Kernel

A minimal, extensible runtime that provides core primitives for coordinating distributed processes, atop which richer coordination abstractions (tuple spaces, channels, workflows) can be layered.

Distinct from a [[Protocol Kernel]], which composes the communication service itself from micro-protocols such as ordering, reliability, failure detection, encryption, and synchronization.
