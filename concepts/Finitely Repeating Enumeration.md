# Finitely Repeating Enumeration

A stream enumerating every element of an infinite target language at least once, with each individual element appearing only finitely many times. It may contain repeats; repetition-free enumeration is stricter. The restriction prevents an adversary from presenting one misleading example infinitely often to a memoryless learner.
