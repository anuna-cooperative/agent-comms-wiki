# Coordinated Attack Problem

**Notation:** `simultaneous action over unreliable communication`.

Two generals must attack together, but their messengers may fail to arrive. Neither attacks without successful communication. Under the specified deterministic protocols, attacking correctly requires common knowledge of the attack. Non-guaranteed delivery prevents the required knowledge, so any protocol preserving the coordination requirement must never attack. This is distinct from FLP consensus impossibility.
