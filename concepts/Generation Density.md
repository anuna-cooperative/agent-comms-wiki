# Generation Density

Coverage of an infinite target language by a generated set, measured against a fixed canonical ordering. Upper density uses a limsup of the fraction of the first n target elements covered; lower density uses a liminf. The paper’s main minimax guarantees concern limsup over rounds of upper set-density, a weaker condition than uniformly high coverage after some stage.
