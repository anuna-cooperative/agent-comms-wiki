# Identification in the Limit

Learning a target language by producing hypotheses that eventually stabilise on a correct candidate. The learner need not know when stabilisation has occurred. This asks for a description of the whole target, a stronger goal than eventually producing valid outputs. Restrictions on what the learner can retain change which families are identifiable.
