# Complexity Profile

A description of how the information needed to specify a system's behavior changes with the scale of observation. [[Dynamics of Complex Systems]], §8.3.5, uses this perspective to compare component behavior with collective behavior. Finer details may disappear at larger scales, so the complexity of a collection cannot be inferred by summing its components. [source PDF](https://fernandonogueiracosta.wordpress.com/wp-content/uploads/2015/08/yaneer-bar-yam-dynamics-of-complex-systems.pdf#page=762)

The flock example (printed pp.746–751; PDF pp.762–767) distinguishes three cases: independent motions tend to average away; identical, coherent motions have a compact collective description; richer collective patterns require interactions producing correlated but differentiated motions. Correlation can preserve behavior at a larger scale while also making its description more redundant. [source PDF](https://fernandonogueiracosta.wordpress.com/wp-content/uploads/2015/08/yaneer-bar-yam-dynamics-of-complex-systems.pdf#page=763)

**Application to agents:** increasing agent count or making agents repeat the same response does not by itself demonstrate richer collective behavior. Evaluate which differentiated interactions matter at the task's scale. This is an application of the model, not a supplied complexity score for [[LLM Agents]].
