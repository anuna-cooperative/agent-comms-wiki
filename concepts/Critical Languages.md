# Critical Languages

In Kleinberg and Mullainathan’s construction, L_n is critical at round t when it contains all observed examples and is a subset of every sample-consistent candidate with index at most n. Critical candidates form a nested chain. The true target eventually stays critical, so sufficiently deep choices support valid generation without identifying the target. The algorithmic version uses finite-prefix approximations instead of arbitrary inclusion tests.
