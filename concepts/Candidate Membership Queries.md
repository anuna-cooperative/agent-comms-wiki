# Candidate Membership Queries

An interface answering whether a supplied element belongs to a named candidate language L_i. In the generation model, access is assumed for the known candidate family. This differs from an oracle for membership in the hidden target K: the learner does not know which candidate index denotes K. Membership tests also do not automatically decide inclusion between infinite languages.
