# Language Generation in the Limit

A learner receives positive examples of an unknown infinite target language from a known candidate family. It succeeds if, after some finite stage, every output is valid. An element-based output must be a target element not yet observed; a set-based output must be an infinite subset of the target. Valid generation need not identify the language or cover it broadly.
