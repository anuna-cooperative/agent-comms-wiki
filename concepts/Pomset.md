# Pomset

A **pomset** is a partially ordered multiset: a collection of distinct event occurrences carrying labels, together with a partial order of required precedence. Repeated labels are allowed, incomparable occurrences express concurrency, and each total ordering compatible with the partial order is a linearization.

Pomsets model one concurrent run directly. A language of pomsets models a process with multiple possible runs. Compared with a [[Mazurkiewicz Trace]], a pomset need not be generated by commuting actions under one fixed label-level independence relation; compared with an [[Event Structure]], it normally describes a single causal history rather than conflict and enabling among alternative histories.
