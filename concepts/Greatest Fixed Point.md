# Greatest Fixed Point

**Notation:** `νX.F(X)`.

The largest solution X to X = F(X), ordered by inclusion of the system points satisfying X. For common knowledge, F(X) = E_G(φ ∧ X): everyone knows both φ and that the same group-knowledge condition holds. The fixed-point formulation also defines the temporal variants, for which simple infinite iteration need not be equivalent.
