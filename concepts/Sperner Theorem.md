# Sperner Theorem

For subsets of an n-element set ordered by inclusion, the largest antichain has size binom(n, floor(n/2)). An antichain contains no pair where one set includes the other. This width of the Boolean lattice controls the paper’s sharp memoryless and sliding-window minimax upper-density bound for finite language families.
